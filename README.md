# Diabetes Prediction
This project predicts whether a person is diabetic based on various health parameters using a Support Vector Machine (SVM) model.
The goal of this project is to predict the likelihood of diabetes using the Pima Indians Diabetes Dataset. It employs a machine learning approach using the Support Vector Machine (SVM) classifier, which is trained on multiple health parameters such as glucose levels, BMI, age, and others.
The model will output a prediction indicating whether the patient is diabetic (1) or not (0).

Dataset
The dataset used in this project is the Pima Indians Diabetes Database, which can be accessed here. The dataset contains the following attributes:

Pregnancies
Glucose
Blood Pressure
Skin Thickness
Insulin
BMI (Body Mass Index)
Diabetes Pedigree Function
Age
Outcome (Target variable: 0 or 1)
